**Capstone Project\: Crime & Socioeconomic Analysis**

- **Project**\: Cornell College capstone econometrics analysis examining FBI crime trends, ACS socioeconomic data, and oter factors to evaluate demographic relationships between crime in Minnesota and its traditonal sociological determinants over time and across COVID.
- **Location**\: The main paper can be rendered from [Main Project/main_econometrics.qmd](Main%20Project/main_econometrics.qmd)\: see the repository structure below.

**Project Contents**
- **Data**\: [data/](data/)\: cleaned and raw datasets used for analysis, including ACS and crime series files.
	- **Key files**\: [data/acs_1_yearly_data.rds](data/acs_1_yearly_data.rds), [data/acs_1yr_ts.rds](data/acs_1yr_ts.rds), [data/acs_5_yearly_data.rds](data/acs_5_yearly_data.rds), [data/acs_5yr_ts.rds](data/acs_5yr_ts.rds), [data/crime_data.rds](data/crime_data.rds), [data/crime_data_merged.rds](data/crime_data_merged.rds), [data/alc_data.rds](data/alc_data.rds)\: Key files used in the main analysis and mapping in the [Main Project/main_econometrics.qmd](Main%20Project/main_econometrics.qmd) scripts.
	- **Downloads**\: [data/downloads/](data/downloads/)\: raw CSV downloads generated by [Main Project/crime_data_scraper.py](Main%20Project/crime_data_scraper.py) (per-tract or per-ward crime files from the FBI's data viewer website).
	- **MN Liquor**\: [data/MN Liquor/](data/MN%20Liquor/)\: Minnesota Department of Revenue liquor sales and tax data.
	- **MISC**\: [data/mapping.rds](data/mapping.rds), [data/mapping_yearly_data.rds](data/mapping_yearly_data.rds), [data/vars.rds](data/vars.rds)\: Data generated through [Main Project/census_imports.R](Main%20Project/census_imports.R) for the purpose of joining crime, census, and alcohol data to the same data frame by county and year.

**Scripts and Analysis**
- **Main Project**\: [Main Project/](Main%20Project/)\: analysis scripts and report citations.
	- **R scripts**\: 
      - [Main Project/census_imports.R](Main%20Project/census_imports.R)\: Tidycensus acs 1 and 5 data imports as well as mapping and key variable generation.
      - [Main Project/crime_data_imports.R](Main%20Project/crime_data_imports.R)\: Merging and pivot of scraped FBI data in the downloads folder creation of large crime data file.
      - [Main Project/crime_data_census_merger.R](Main%20Project/crime_data_census_merger.R)\: Merge of the imported crime, census, and alcohol data with varibles used in [Main Project/main_econometrics.qmd](Main%20Project/main_econometrics.qmd) generated.
	  - [Main Project/alc_imports.R](Main%20Project/alc_imports.R)\: Handling of the MN Dept of Revenue data and creation of the alcohol data file.
	- **Python scraper**\: [Main Project/crime_data_scraper.py](Main%20Project/crime_data_scraper.py)\: Selenium scraper tool to download raw crime CSVs into the downloads folder.
	- **Quarto report**\: [Main Project/main_econometrics.qmd](Main%20Project/main_econometrics.qmd) and its rendered output linked to the [Netlify site](https\://minnesotacrime.netlify.app/main_econometrics.html) through [Main Project/_site/](Main%20Project/_site/).

**Supporting Files**
- **AI & notes**\: [data/ai_mappings.csv](data/ai_mappings.csv)\: csv mapping files for the joining of police department by county built using data found in [Relevant Literature/ORI Directory.pdf](Relevant%20Literature/ORI%20Directory.pdf). 

**How to reproduce**
- **Environment**\: Use R (version >= 4.0) with tidyverse, readr, and quarto for rendering reports. Python 3.x for the scraper.
- **Typical workflow**\: run data import scripts in [Main Project/](Main%20Project/) to regenerate [data/](data/) objects, then render [Main Project/main_econometrics.qmd](Main%20Project/main_econometrics.qmd) to reproduce the report.

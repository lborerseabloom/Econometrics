**Capstone Project: Crime & Socioeconomic Analysis**

- **Project:**: Capstone econometrics analysis examining crime trends, ACS socioeconomic data, and census joins to evaluate policy and demographic relationships.
- **Location:**: Root of this workspace — see the repository structure below.

**Project Contents**

- **Data:**: [data/](data/) — cleaned and raw datasets used for analysis, including ACS and crime series files.
	- **Key files**: [data/acs_1_yearly_data.rds](data/acs_1_yearly_data.rds), [data/acs_1yr_ts.rds](data/acs_1yr_ts.rds), [data/acs_5_yearly_data.rds](data/acs_5_yearly_data.rds), [data/acs_5yr_ts.rds](data/acs_5yr_ts.rds), [data/crime_data.rds](data/crime_data.rds), [data/crime_data_merged.rds](data/crime_data_merged.rds)
	- **Downloads**: [data/downloads/](data/downloads/) — raw CSV downloads generated by [Main Project/crime_data_scraper.py](Main%20Project/crime_data_scraper.py) (per-tract or per-ward crime files from the FBI's data viewer website).

**Scripts and Analysis**
- **Main Project**: [Main Project/](Main%20Project/) — analysis scripts and report sources.
	- **R scripts**: 
      - [Main Project/census_imports.R](Main%20Project/census_imports.R): Tidycensus acs 1 and 5 data imports.
      - [Main Project/crime_data_imports.R](Main%20Project/crime_data_imports.R): Merging and pivot of scraped FBI data in the downloads folder.
      - [Main Project/crime_data_census_merger.R](Main%20Project/crime_data_census_merger.R): Merge of the imported crime and census data with varibles used in [Main Project/main_econometrics.qmd](Main%20Project/main_econometrics.qmd) generated.
	- **Python scraper**: [Main Project/crime_data_scraper.py](Main%20Project/crime_data_scraper.py): Selenium scraper tool to download raw crime CSVs into the downloads folder.
	- **Quarto report**: [Main Project/main_econometrics.qmd](Main%20Project/main_econometrics.qmd) and its rendered output [Main Project/main_econometrics.html](Main%20Project/main_econometrics.html).

**Presentation Materials**
- [Presentation/](Presentation/) — slides and related assets used for project presentations.
	- Example slides: [Presentation/CapstonePresentation.qmd](Presentation/CapstonePresentation.qmd), exported HTML slides in the same folder.

**Supporting Files**
- **AI & notes**: [data/ai_alcohol_effects.csv](data/ai_alcohol_effects.csv), [data/ai_mappings.csv](data/ai_mappings.csv): csv mapping files for the joining of police department by county built using data found in [Relevant Literature/ORI Directory.pdf](Relevant%20Literature/ORI%20Directory.pdf) and [Relevant Literature/Alcohol Costs by County.pdf](Relevant%20Literature/Alcohol%20Costs%20by%20County.pdf) 

**How to reproduce**
- **Environment:**: Use R (version >= 4.0) with tidyverse, readr, and quarto for rendering reports. Python 3.x for the scraper.
- **Typical workflow:**: run data import scripts in [Main Project/](Main%20Project/) to regenerate `data/` objects, then render [Main Project/main_econometrics.qmd](Main%20Project/main_econometrics.qmd) to reproduce the report.
